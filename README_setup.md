# Remote Desktop Setup Instructions

This setup provides a Dockerized Ubuntu Desktop accessible via RDP and noVNC (Web Browser) with increased resource limits (16GB RAM) and a modern UI theme.
A persistent storage volume mapped to `./.data` is included to provide storage space.

## 1. Local Requirements
- Docker and Docker Compose installed.
- Ensure you have at least 500GB of storage available on your host machine.
- You must set your own secure credentials by exporting the following environment variables before running docker-compose:
  ```
  export RDP_USER=yourusername
  export RDP_PASSWORD=yoursecretpassword
  ```
  If you don't provide these, the build and startup will fail for security reasons.

## 2. Start the Container
```
docker-compose up -d --build
```

## 3. Expose to the Internet
Run the included tunnel script to generate public URLs.
```
./start-tunnel.sh
```

## 4. Connect
- **RDP:** Connect your RDP client to the hostname and port generated by the Pinggy tunnel.
- **Web Browser (noVNC):** Access the public URL generated by localhost.run. You will be prompted for basic authentication.
